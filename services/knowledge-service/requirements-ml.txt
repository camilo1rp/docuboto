# knowledge-service — CAPA ML OPCIONAL (E21 Inc.1).
#
# Contiene la única dependencia pesada del servicio: `sentence-transformers`, que respalda
# `EMBEDDING_PROVIDER=local_st` (`LocalSentenceTransformerProvider`) — el proveedor de
# embeddings LOCAL y SOBERANO, el único junto con `stub` que puede embeber material
# `nivel_seguridad >= RESERVADA` (ver `app/core/clearance.py::LOCAL_EMBEDDING_PROVIDERS`).
#
# Se instala solo si el build recibe `--build-arg WITH_ML=1` (el DEFAULT del Dockerfile),
# de modo que una instalación tenant local obtiene la imagen soberana completa sin cambiar
# nada. `WITH_ML=0` produce una imagen ligera para máquinas que no pueden ejecutar modelos
# locales; el código es idéntico (import perezoso en `embeddings.py::_ensure_loaded`).
#
# CPU-ONLY a propósito: el índice de PyTorch para CPU evita las ~22 wheels `nvidia-*` +
# `triton` (unos 5 GB) que el índice por defecto de PyPI arrastra. Este servicio hace
# inferencia de un modelo de 384 dimensiones; no usa GPU. Regenerar el lock con:
#
#   docker run --rm -v "$PWD":/repo -w /repo python:3.11-slim sh -c \
#     'pip install -q uv && uv pip compile services/knowledge-service/requirements-ml.txt \
#        -o services/knowledge-service/requirements-ml.lock --python-version 3.11 \
#        --index-strategy unsafe-best-match --no-header'
--extra-index-url https://download.pytorch.org/whl/cpu

-r requirements.txt
